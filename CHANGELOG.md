# Changelog

Notable changes to Insider Cat, newest first.

## [0.2.0] - 2026-11-09

The **Projects** release: a Projects board that groups work by what it needs from
the person, live conversation cards, resolved state, message folding and
reactions from project conversations, and skill guidance so the Cat coordinates
work instead of doing it itself.

### Added

- Group work by attention and track it per Cat ([#5](https://github.com/enyst/insider/pull/5)).
- Live conversation cards and Resolved work ([#6](https://github.com/enyst/insider/pull/6)).
- Workers learn which Cat is talking to them and where to put decisions ([#8](https://github.com/enyst/insider/pull/8)).
- Label messages another conversation sent ([#9](https://github.com/enyst/insider/pull/9)).
- Show emoji reactions in Cat chat ([#10](https://github.com/enyst/insider/pull/10)).
- The Cat delegates work and routes updates to conversations ([#12](https://github.com/enyst/insider/pull/12)).
- Fold coordinator updates and follow the single send route ([#14](https://github.com/enyst/insider/pull/14)).
- Show what an asking conversation needs on its card ([#15](https://github.com/enyst/insider/pull/15)).
- Fold person copies and replies from project conversations ([#16](https://github.com/enyst/insider/pull/16)).

### Fixed

- Follow light Canvas themes such as Paper ([#7](https://github.com/enyst/insider/pull/7)).
- Keep live cards after transient errors; tie Voice answers to their request ([#11](https://github.com/enyst/insider/pull/11)).
- Send spoken requests through idle-only server admission ([#13](https://github.com/enyst/insider/pull/13)).
